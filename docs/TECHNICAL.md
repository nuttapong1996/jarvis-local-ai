# รายละเอียดเชิงเทคนิค — น้องจาง (Jarvis ไทย)

> สำหรับคนที่อยากรู้ว่าข้างในทำงานยังไง · คู่มือใช้งานแบบง่ายอยู่ที่ [README](../README.md)

ผู้ช่วยเสียงภาษาไทยบน macOS แบบ **full duplex**: ฟังตลอดเวลา ไม่ต้องกดปุ่ม เรียก **"น้องจาง"** แล้วคุยต่อเนื่องได้เหมือนเพื่อน
พูดแทรกได้ เสียงผู้ชาย พูดเร็ว มีหน้าจอ **J.A.R.V.I.S** ลอยบนจอแบบในหนัง และทำงานในเครื่องเกือบทั้งหมด
ได้แรงบันดาลใจจาก [hey-jev](https://github.com/henryklunaris/hey-jev) แต่ปรับเป็นภาษาไทยทั้งหมด

```
"น้องจาง วันนี้เหนื่อยจังเลย"                  → "เฮ้ย เหนื่อยมากเหรอ ..." (คุยต่อได้ 30 วิโดยไม่ต้องเรียกชื่อซ้ำ)
"น้องจาง เปิดแอปสโตร์ให้หน่อย"                → เปิด App Store (รู้จักทุกแอปที่ติดตั้งในเครื่อง)
"น้องจาง หยุดเพลงแล้วเปิดสแล็ก"               → หยุดเพลง + เปิด Slack (Jev แยกสองคำสั่งเอง)
"น้องจาง ตั้งเสียงไว้ที่สามสิบห้า"               → ตั้งเสียง 35%
"น้องจาง หาเพลงน้องเนยในยูทูบ เปิดให้ฟังหน่อย"   → เอเจนต์เปิด Chrome ค้นแล้วกดเล่นให้
"น้องจาง ราคาทองวันนี้เท่าไหร่"                 → เป็นคำถามก็จริง แต่ต้องใช้ข้อมูลสด → ค้นเว็บให้
```

## ทำงานอย่างไร

```
ไมค์ (ฟังตลอด) ─► ตัดเสียงสะท้อน AEC (WebRTC ผ่าน livekit) ─► Silero VAD ตัดเป็นประโยค
   ─► ถอดเสียงไทยในเครื่อง: Apple DictationTranscriber (macOS 26+) · สำรอง Whisper large-v3-turbo (MLX)
   ─► ได้ยิน "น้องจาง" หรือกำลังคุยกันอยู่ไหม?
   ─► Jev (TypeSafe) ตัดสินใจแบบ speculative fan-out: ถามทุกคำถามในครั้งเดียว
        category · compound · action · app (ทุกแอปในเครื่อง) · volume · chat   ← พร้อมกันนั้น LLM ในเครื่องเริ่มคิดคำตอบไว้ก่อน
        สองคำสั่ง → ถามรอบสอง แยก FIRST / SECOND · ไม่มั่นใจ → ถอดเสียงซ้ำด้วย Typhoon ก่อนขอให้พูดใหม่
   ─► สั่ง macOS (osascript/shell)  |  ท่องเว็บ (Playwright + LLM)  |  คุย/ตอบคำถาม (LLM ในเครื่อง)
   ─► พูดตอบด้วย say -v Kanya แบบทุ้ม เร็ว (เล่นผ่านลำโพงเอง จึงหยุดได้ทันทีเมื่อผู้ใช้พูดแทรก)
```

- **คุยต่อเนื่องแบบเพื่อน**: หลังเรียกชื่อแล้วคุยต่อได้ 30 วินาทีโดยไม่ต้องเรียกซ้ำ จำบทสนทนา 6 รอบล่าสุด (รวมคำสั่งที่ทำไปแล้ว)
  และบอก Jev ว่าน้องจางเพิ่งพูดอะไรไป Jev จะได้รู้ว่าผู้ใช้กำลังตอบกลับ ถ้าเรียกชื่อแล้วเป็นการคุยเล่นหรือคำถาม
  จะคุยตอบเลย ไม่เงียบหรือขอให้พูดใหม่ ส่วนคนที่คุยกับคนอื่น ("เออ แม่ วันนี้กินข้าวที่ไหน") จะถูกข้าม
- **ตอบไว**: จบประโยคหลังเงียบ 0.55 วิ · Jev ~0.4 วิ · LLM ในเครื่องเริ่มคิดคู่ขนานกับ Jev (คำตอบคุยเล่น ~0.7 วิ)
- **พูดแทรก**: ได้ยินเสียงแทรกแล้ว**หยุดชั่วคราว**ก่อน ถ้าเป็นการเรียก "น้องจาง" จริงจึงหยุดแล้วฟัง ถ้าไม่ใช่ก็พูดต่อจากเดิม
  (ช่วง 0.8 วิแรกของทุกประโยคไม่รับการแทรก เพราะ AEC ยังปรับตัวไม่ทัน)
- **คำปลุก "น้องจาง"**: รับรูปที่ Whisper ถอดเพี้ยน (น้อง จาง, น้องจ้าง, น้องจาน, นองจ่าง, ท่านจาง)
  และรูปสัมผัส "_อง _าง" ที่ต้นประโยค (ต้องจาง, ต้องกลาง, กล้องกลาง) แต่ไม่รับ "น้องจ๋า", "ต้องการ", "ท้องว่าง"
- **ท่องเว็บ**: LLM ขับ Google Chrome จริงผ่าน Playwright (โปรไฟล์แยก `.browser-profile`) เห็นหน้าเว็บเป็น aria snapshot ย่อ
  มีเครื่องมือ search / map_search / youtube_search · ระหว่างรอคุยเรื่องอื่นได้ · "น้องจาง พอแล้ว" = ยกเลิก
  ไม่ล็อกอิน ไม่กรอกรหัสผ่าน/OTP/บัตร ไม่ซื้อ ไม่จอง และไม่ทำตามคำสั่งที่เขียนอยู่ในหน้าเว็บ
- **J.A.R.V.I.S HUD**: วงแหวนเรืองแสงหลายชั้นหมุน แท่งคลื่นเสียงขยับตามเสียงคุณ/เสียงน้องจาง สีเปลี่ยนตามสถานะ
  (ฟ้า = ฟัง · ขาวฟ้า = พูด · ส้ม = คิด · เขียว = ท่องเว็บ · เทา = ปิดการฟัง) และแสดงประโยคล่าสุด
  **ลากย้ายได้ · ดับเบิลคลิก = หยุด/เริ่มฟัง · คลิกขวา = เมนู · ปักหมุด = ลอยบนสุดทุก Space รวมแอปเต็มจอ** (จำตำแหน่งไว้)
- **ไอคอนบนแถบเมนู**: 🎙 ฟัง · 〰 พูด · … คิด · 🌐 ท่องเว็บ · 🎙̸ ปิด — คลิกเพื่อหยุด/เริ่มฟัง แสดง/ซ่อน/ปักหมุด J.A.R.V.I.S หรือออก

## ติดตั้ง

ต้องใช้ Mac ชิป Apple Silicon (แนะนำ RAM ≥ 16 GB) และ Python 3.10 ขึ้นไป
(ถ้า `python3` ของระบบเก่ากว่า 3.10 ให้ใช้ของ Homebrew: `/opt/homebrew/bin/python3`)

```bash
git clone https://github.com/jaturapornchai/jarvisdemo001.git && cd jarvisdemo001
/opt/homebrew/bin/python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                        # แล้วใส่ TYPESAFE_API_KEY
```

- เสียงภาษาไทย **Kanya**: เช็คด้วย `say -v '?' | grep -i kanya` ถ้าไม่มีให้ติดตั้งที่
  System Settings › Accessibility › Spoken Content › System Voice › Manage Voices… › ภาษาไทย › Kanya
  (macOS มีเสียงไทยแค่ Kanya ซึ่งเป็นเสียงผู้หญิง น้องจางจึงกดให้ทุ้มด้วย `TTS_PITCH=28`)
- ครั้งแรกจะดาวน์โหลดโมเดลเอง: Whisper ~1.6 GB และ LLM ในเครื่อง ~2.3 GB
  ถ้าอยากได้ "ความเห็นที่สอง" ให้โหลด Typhoon เพิ่ม ~1.6 GB:
  `.venv/bin/python -c "from huggingface_hub import snapshot_download as d; d('chayapats/typhoon-whisper-turbo-mlx')"`

## วิธีใช้

```bash
./run_app.sh                                       # แนะนำ: เปิดเป็นแอป "Jarvis" ของตัวเอง + โชว์ log สด (Ctrl+C = ปิด)
./run_app.sh --selftest                            # ทดสอบอ่านจอ/เมาส์/คีย์บอร์ดกับหน้าต่างทดสอบของตัวเอง (ไม่แตะงานคุณ)
python jarvis.py                                   # ฟังไมค์ + J.A.R.V.I.S บนจอ (สิทธิ์จะไปผูกกับแอปเทอร์มินัลแทน)
python jarvis.py --dry-run                         # ฟังและคุยได้ แต่แค่ print คำสั่ง ไม่สั่งเครื่องจริง
python jarvis.py --text "หยุดเพลงแล้วเปิดสแล็ก"     # สั่งด้วยข้อความ ไม่ใช้ไมค์
python jarvis.py --eval                            # วัดความแม่นกับชุดประโยคทดสอบภาษาไทย
python jarvis.py --wav file.wav --dry-run          # ป้อนไฟล์เสียงแทนไมค์ (ทดสอบ VAD + Whisper + คำปลุก)
```

ทุกครั้งที่เรียก Jev จะพิมพ์ trace: เวลา, ms, โมเดล, จำนวน token และคำตอบกับ confidence ของทุกคำถาม
(⚠ = ต่ำกว่า `CONF_MIN`; คำถามที่ไม่เกี่ยวกับคำสั่งนั้นเป็นคำถาม "เผื่อไว้" ของ fan-out ซึ่งโค้ดไม่ได้ใช้)

## ตั้งค่า `.env` (ดูรายละเอียดใน `.env.example`)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |

| `TYPESAFE_API_KEY` | – (**จำเป็น**) | คีย์ของ TypeSafe (โมเดล Jev) |
| `LLM_MODE` | `local` | `local` = LLM ในเครื่อง · `cloud` = OpenRouter/Gemini |
| `LOCAL_LLM_MODEL` | `tawankri/typhoon2.5-qwen3-4b-mlx-4Bit` | โมเดลในเครื่อง (Typhoon 2.5 ของ SCB10X, 4-bit) |
| `OPENROUTER_API_KEY` / `GOOGLE_API_KEY` | – | ใช้เมื่อ `LLM_MODE=cloud` |
| `TTS_VOICE` / `TTS_RATE` / `TTS_PITCH` | `Kanya` / `230` / `28` | เสียง ความเร็ว (คำ/นาที) และความทุ้ม (เว้นว่าง = เสียงปกติ) |
| `WAKE_WORD` / `CONVO_SEC` | `น้องจาง` / `30` | คำปลุก (`off` = ฟังทุกประโยค) / คุยต่อได้กี่วินาทีโดยไม่เรียกชื่อซ้ำ |

| `BARGE_IN` / `SILENCE_MS` / `VAD_THRESHOLD` | `auto` / `550` / `0.5` | การพูดแทรก / เงียบนานเท่าไหร่ถือว่าจบ / ความไวจับเสียงพูด |
| `EXTRA_APPS` | `auto` | ให้สั่งเปิด/ปิดได้ทุกแอปที่ติดตั้ง |
| `MENUBAR` / `HUD` | `on` / `on` | ไอคอนแถบเมนู / หน้าจอ J.A.R.V.I.S |
| `STT_ENGINE` | `auto` | ตัวถอดเสียงหลัก: `auto` = ของ Apple ในเครื่อง (macOS 26+) ไม่งั้น Whisper · `apple` · `whisper` |
| `MLX_WHISPER_REPO` / `STT_SECOND_OPINION` | turbo / `auto` | Whisper (ตัวสำรอง) / ถอดซ้ำด้วย Typhoon เมื่อ Jev ไม่มั่นใจ |
| `SAVE_UTTERANCES` | – | ใส่ชื่อโฟลเดอร์ (เช่น `recordings`) เพื่อเก็บเสียงแต่ละประโยคไว้ทดสอบ (เก็บเสียงทุกคนในห้อง ใช้เท่าที่จำเป็น) |
| `AGENT_BRAIN` | `jev` | สมองของเอเจนต์คุมคอม: `jev` = Jev เลือกทีละขั้นจากรายการบนจอ (~0.4 วิ/ขั้น) · `llm` = LLM เรียกเครื่องมือ |
| `CHROME_PROFILE` | – | เปิด Chrome ด้วยโปรไฟล์ไหน (ชื่อหรือโฟลเดอร์ เช่น `Default`) เว้นว่าง = โปรไฟล์ที่ใช้ล่าสุด |
| `LOG_HEARD` | – | `all` = พิมพ์ข้อความที่ได้ยินแต่ไม่ได้เรียกน้องจางลง log (ปกติบอกแค่ความยาว เพื่อความเป็นส่วนตัว) |

แก้รายชื่อแอป เว็บ คำสั่ง และประโยคตอบได้ใน dict `APPS`, `SITES`, `ACTIONS`, `REPLIES` บนสุดของ `jarvis.py`
(คำอธิบายเขียนเป็นอังกฤษ แล้วแนบคำไทยที่คนใช้เรียกในวงเล็บ เพราะ Jev เก่งภาษาอังกฤษที่สุด)

## ทำให้ตอบไว (ใช้ Jev แทน LLM ให้มากที่สุด)

- **คุยเล่น** (ทักทาย ขอบคุณ ชม บ่น เหนื่อย/หิว/เบื่อ ถามว่าทำอะไรได้ ฯลฯ): Jev จัดประเภทไปพร้อมกับการตัดสินใจรอบแรก
  (ถามในครั้งเดียวกัน ไม่เพิ่มเวลา) แล้วตอบจาก `CHAT_REPLIES` ทันที — ใช้ LLM เฉพาะคำถามที่ต้องคิดจริง
- **เสียงพูดสำเร็จรูป**: `say` ใช้ ~0.43 วิทุกประโยค → สังเคราะห์ประโยคสำเร็จรูปเก็บไว้ใน `.tts-cache/` (ครั้งแรกเบื้องหลัง ~2 นาที)
  คำตอบจาก LLM ไม่ถูกเก็บลงดิสก์
- **คุมคอม**: Jev เลือกขั้นต่อไป + ชิ้นบนจอที่จะกด + ปุ่มลัด + แอป ในการเรียกครั้งเดียวต่อขั้น
  (LLM ใช้แค่ดึงข้อความที่ต้องพิมพ์) · ด่านในโค้ด: ไม่กดปุ่มอันตราย (ลบ/ส่ง/ซื้อ/ล้างถังขยะ/ไม่บันทึก ฯลฯ) ปุ่มไม่มีชื่อ,
  ไม่กด Enter ในแอปแชท/ตอนมีปุ่มอันตราย, ไม่พิมพ์ถ้าไม่มีช่องพิมพ์ถูกเลือก
- **ความเห็นที่สอง**: เรียกชื่อมา → เริ่มถอดเสียงซ้ำด้วย Typhoon ไปพร้อมกับ Jev เลย
- log มีบรรทัด `⏱ ตอบใน … ms` ทุกประโยค

## Chrome ของคุณ vs Chrome ของน้องจาง

เอเจนต์เว็บใช้ Chrome อีกตัวที่มีโปรไฟล์แยก (`.browser-profile`) เพราะ Chrome ไม่ยอมให้โปรแกรมคุมโปรไฟล์หลัก
และไม่ควรให้เอเจนต์ใช้บัญชีที่คุณล็อกอินไว้ · คำสั่ง "เปิด Chrome" / เปิดเว็บ / "ปิด Chrome" จะทำกับ Chrome ของคุณเสมอ
(เปิดด้วยโปรไฟล์ที่ใช้ล่าสุด ข้ามหน้าเลือกโปรไฟล์) ไม่ไปโผล่ในตัวของน้องจาง

## สิทธิ์ของ macOS

macOS ให้สิทธิ์กับ "แอปที่รับผิดชอบ" โปรเซส ไม่ใช่ตัว python:
- เปิดด้วย `./run_app.sh` → สิทธิ์ผูกกับแอป **Jarvis** (`Jarvis.app` ที่ `macos/build_app.sh` สร้าง) แนะนำวิธีนี้
  เพราะไม่ต้องให้สิทธิ์อ่านจอ/คุมเครื่องกับทั้งแอปเทอร์มินัลหรือแอป Claude
- เปิดด้วย `python jarvis.py` → สิทธิ์ผูกกับแอปที่รันคำสั่ง (Terminal, iTerm, VS Code หรือแอป Claude)

ให้ที่ System Settings › Privacy & Security (ถ้าไม่มีชื่อในรายการ สั่งงานนั้นหนึ่งครั้ง macOS จะเพิ่มชื่อให้)

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| **Microphone** | ฟังเสียง (ถ้าไม่ให้ ไมค์จะส่งแต่ความเงียบ น้องจางจะเตือน) |
| **Automation** | ส่ง Apple Events ไปยัง System Events (โหมดมืด), Music/Spotify และแอปที่สั่งปิด (ขึ้นถามครั้งแรกทีละแอป) |
| **Accessibility** | คุมเครื่อง: คลิก พิมพ์ อ่าน/กดปุ่มของแอป (มีผลทันที) |
| **Screen & System Audio Recording** | อ่านจอ (OCR) และแคปหน้าจอ — เปิดแล้วต้องปิดเปิดน้องจางใหม่ |
| ~~Speech Recognition~~ | **ไม่ต้องใช้** ตัวถอดเสียงของ Apple ที่ใช้ (DictationTranscriber) ไม่ต้องขอสิทธิ์ |
| ~~Input Monitoring~~ | **ไม่ต้องใช้** เพราะเลิกใช้ปุ่มกดค้าง (pynput) |

ตรวจว่าครบไหมด้วย `./run_app.sh --selftest` — เปิดหน้าต่างทดสอบของตัวเอง ทดสอบคลิก/พิมพ์/อ่านจอกับหน้าต่างนั้นเท่านั้น
(พิมพ์เฉพาะเมื่อพิสูจน์ด้วยการกด Shift เปล่าๆ แล้วว่าคีย์บอร์ดไปถึงหน้าต่างทดสอบจริง) แล้วคืนเมาส์ที่เดิม
หมายเหตุ: build `Jarvis.app` ใหม่ = ลายเซ็นเปลี่ยน macOS จะลืมสิทธิ์ที่ให้ไว้ ต้องเปิดใหม่อีกรอบ

ถ้าคำสั่งไหนโดน macOS บล็อก ใน log จะขึ้น 🔐 บอกว่าต้องไปเปิดสิทธิ์ที่ไหน

ชุด held-out 17 ประโยคที่ไม่เคยใช้จูน: **17/17** · Jev ~0.45 วินาทีต่อประโยค
token ของ eval ทั้งชุด 171,567 → 115,031 (−33%) รอบสองของคำสั่งซ้อน ~8,000 → ~1,130 tokens
เอเจนต์เว็บ: aria snapshot ที่ย่อแล้ว ~4,000 ตัวอักษรต่อหน้า (ทีมวัด 21,564 → 7,657 tokens ต่องาน) และถอดรหัส URL ภาษาไทยก่อนส่ง

**LLM ในเครื่อง** (Typhoon2.5-Qwen3-4B 4-bit บน M5 Pro): ตอบ ~0.5–0.8 วิ (Gemini ฟรี ~1.4 วิ และติดเพดานต่อนาทีบ่อย)
ข้อเท็จจริงถูก 8/10 ในชุดทดสอบ (Gemini 10/10) · ท่องเว็บงานยากทำสำเร็จ 1/3 (Gemini 3/3) → งานเว็บซับซ้อนควรใช้ `LLM_MODE=cloud`
หรือโมเดลในเครื่องที่ใหญ่ขึ้น (เช่น `typhoon-ai/typhoon2.1-gemma3-12b-mlx-4bit` ~7 GB)

**ถอดเสียงจริงของผู้ใช้** (139 ประโยคที่พูดใส่ไมค์จริง): ตัวถอดเสียงของ Apple ดีกว่า Whisper 69 ประโยค · เท่ากัน 34 ·
Whisper ดีกว่า 1 · ถอดไม่ได้/ใช้ไม่ได้ 32 → 20 · จับคำปลุกได้ 55 → 56 (หลังรับรูปที่ Apple ได้ยินเพี้ยน เช่น "ล้างจาน" "น้องแจง")
· เร็วขึ้น ~212 → ~100 ms ต่อประโยค → ใช้ของ Apple เป็นหลัก Whisper เป็นตัวสำรอง และ Typhoon เป็น "ความเห็นที่สอง"

## หมายเหตุการออกแบบ

- **ระดับเสียงเป็น Score 10 ระดับ (10–100%)** ไม่ใช่ 11 เพราะ API ของ TypeSafe ปฏิเสธเกิน 10 ระดับ
  (`400 Too many score levels. Must have at most 10 levels.`) ส่วน 0% ใช้ `volume_mute` และตัวเลขที่พูดมาโค้ดอ่านเอง
- `NoulAnswer` ไม่มี confidence จึงคำนวณเป็น `max(p, 1-p)`
- **AEC delay** คำนวณจาก `time_info` ของ PortAudio (~95 ms) เพราะ `stream.latency` ที่รายงานเชื่อไม่ได้
  (เคยได้ 683 ms เกินเพดาน 500 ms ของ WebRTC ทำให้ AEC พังจนน้องจางขัดจังหวะตัวเอง)
- Whisper ชอบแต่งประโยคตอนเงียบและพูดวนซ้ำ มีตัวกรอง จำกัดความยาวผลลัพธ์ตามความยาวเสียง ถอดใหม่แบบไม่มีคำใบ้เมื่อวน
  และตัดท่อนที่ไม่มั่นใจ (avg_logprob < −1 หรือ compression ratio > 2.4)
- คนไทยพูด ร เป็น ล บ่อย ("โรงแรม" → "ลงแลน") เอเจนต์เว็บและ LLM จึงถูกสั่งให้ตีความความหมายก่อนเสมอ
- LLM ในเครื่อง: `mlx_lm.server` ผูก 127.0.0.1 เท่านั้น, จำกัด prompt cache 2 GB (ไม่จำกัดเคยบวมถึง 18 GB แล้วค้าง),
  temperature ≤ 0.2 (โมเดล 4B มั่วง่าย), ตรวจก่อนว่าพอร์ตเป็นเซิร์ฟเวอร์ของเราจริง ไม่งั้นเลื่อนหาพอร์ตว่าง
- Chrome ของน้องจางยังรันต่อหลังปิดหน้าต่างหมด (ปกติของ macOS) ซึ่งทำให้ CDP ต่อไม่ได้ → เปิดแท็บเปล่าให้ก่อนต่อ
- ไม่มี Spotify คำสั่งเพลงจะใช้ Music.app แทน · สั่งเปิดแอปที่ไม่มีในเครื่อง จะตอบว่าไม่พบแอป
